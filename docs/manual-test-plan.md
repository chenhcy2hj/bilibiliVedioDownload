# 手动测试方案（M1–M5 验收）

> 用途：在本地亲手验证已实现功能（FastAPI 后端 + Vue3/three.js 前端）。
> 测试对象：当前代码（M6 打包已交付，macOS/Windows 打包版同样适用；打包版专项见 §4 Cookie 无感获取与 §5 下载）。
> 配套文档：`docs/design-analysis.md`（设计）、`docs/development-guide.md`（规范）。

---

## 0. 测试准备

### 0.1 环境（已满足则跳过）
- [ ] `ffmpeg -version` 可执行（已装 9.0.1）
- [ ] `venv/bin/python --version` = 3.12
- [ ] `frontend/node_modules` 已安装

### 0.2 启动被测系统（二选一）

**方式 A：开发双服务**
```bash
# 终端 1
cd backend && ../venv/bin/uvicorn app.main:app --reload --port 8000
# 终端 2
cd frontend && npm run dev
# 打开 http://localhost:5173
```

**方式 B：生产单端口**
```bash
cd frontend && npm run build   # 若 dist 未构建
cd backend && ../venv/bin/uvicorn app.main:app --port 8000
# 打开 http://127.0.0.1:8000
```

## 4. Cookie（C）

| # | 操作 | 预期 | 结果 |
|---|------|------|------|
| C01 | 点击"获取 Cookie" | 新窗口打开 bilibili.com；页面出现书签引导框 | |

## 8. 错误与边界（E）

| # | 操作 | 预期 | 结果 |
|---|------|------|------|
| E01 | 无 Cookie 提交任务（先清空 Cookie 文件） | 任务快速变红 `failed`；原因"Cookie 失效，请重新获取"；CookieBar 出现**联动横幅**"立即重新获取" | |
| E02 | 输出目录设为只读（`chmod 555`）后下载 | `failed(path)` + 建议"在设置中修改下载目录" | |
| E03 | 断网后提交任务 | `failed(network)` + 建议"检查网络" | |
| E04 | 关闭后端后打开前端 | 页面不崩溃；WS 状态 closed 并在后端恢复后自动重连 | |
| E05 | 表单提交瞬间连点两次 | 按钮禁用中，不产生重复创建 | |
| E06 | 提交 20 个 URL | 全部入队串行执行；无 500 | |
